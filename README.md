# Retail Sales Analysis & Visualization

A beginner-level data analysis project using Python to explore a small retail sales dataset and practice data visualization with Pandas, Matplotlib, and Seaborn.

## Project Overview

This notebook demonstrates how to inspect sales data, calculate revenue, group records, and visualize patterns using different chart types.

## Analysis Covered

- Sales and revenue calculations
- Revenue analysis by city
- Monthly revenue visualization
- Product quantity analysis
- Price and revenue distributions
- Electronics revenue distribution
- UPI payment analysis
- High-value and regular order comparisons
- Quantity versus revenue scatter plot
- Payment method distribution
- Histogram, scatter plot, pie chart, and boxplot examples

The notebook also contains separate practice examples, including study-hours versus exam-scores and a salary boxplot.

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## How to Run

### Google Colab

1. Open Google Colab.
2. Upload `Retail_Sales_Analysis.ipynb`.
3. Run the notebook cells from top to bottom.

### Run Locally

1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Open the notebook using Jupyter:

   ```bash
   jupyter notebook
   ```

## Note

This repository presents the notebook as a learning and practice project. The analysis reflects the sample data and exercises included in the notebook; results should not be interpreted as representative of a real retail business.
